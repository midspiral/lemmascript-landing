05

Atmosphere

The background you’re looking at right now.

A fixed .atmosphere layer (in base.css) composites three things: a top accent glow, a soft film grain (overlay blend, lifts the canvas to a lighter tone), and an edge vignette that pulls focus to center. It lives on its own element so blend modes composite correctly.

2//@ requires amount >= 0
3//@ ensures  \result >= 0 && \result <= balance

5  return amount > balance ? 0 : balance - amount;
